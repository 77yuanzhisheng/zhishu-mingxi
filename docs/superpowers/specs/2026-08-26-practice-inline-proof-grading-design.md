# 自测内联证明题批阅设计

日期：2026-08-26

## 目标

将证明题自动批阅嵌入自测练习。学生完成拍照 OCR 后可校对答案，提交时调用现有 `POST /api/grading/grade`，在当前题目下展示结果，并在批阅成功后上报学习事件。

## 范围

本轮只接入证明题；计算题不改动。保留现有独立批阅代码作为兼容实现，但不新增独立入口或页面，主流程从自测证明题进入。

## 数据流

前端使用当前自测题的题干、标准答案、知识点和 OCR 校对文本组装 `GradeRequest`。由于自测题 ID 与结构化题库 ID 可能不同，直接传 `question`、`reference_answer`、`kp` 和 `knowledge_points`，不依赖 `question_id` 解析题库。

批阅成功后，结果保存在前端题目状态中并渲染；随后调用 `POST /api/learning/events`。`is_correct` 为人工复核时 `null`，否则总分达到 60 分记为正确，低于 60 分记为错误。批阅失败时保留答案文本，显示可重试错误，不上报学习事件。

## 页面行为

- 提交期间按钮禁用，并显示“正在智能批阅”。
- 成功结果显示总分、五维得分及上限、反馈、错误类型、评分依据、人工复核提示。
- 无结构性错误时明确显示“未识别到结构性错误”。
- 题目切换或列表重渲染后恢复已完成的批阅结果。
- 提交前不显示标准答案。
- 结果卡提供参考答案折叠内容，避免影响作答前流程。

## 验证

进行 JavaScript 语法检查、后端相关测试、编译检查，并使用可控的接口模拟验证 grade 成功/失败与学习事件规则。真实模型调用仍取决于本地模型服务。
