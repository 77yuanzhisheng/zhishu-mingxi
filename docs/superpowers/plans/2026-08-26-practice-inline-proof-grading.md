# 自测内联证明题批阅实施计划

## 任务 1：规格与状态契约

- 写入设计规格并确认字段映射、60 分及人工复核规则。
- 检查现有 `GradeResponse` 和学习事件接口，避免复用旧批阅字段。

## 任务 2：先写回归测试

- 添加前端可独立验证的批阅结果格式化和正确性判定测试；若项目没有 JS 测试运行器，则以 Node 可执行 helper 加静态断言覆盖核心契约。
- 运行测试，先确认新行为在实现前失败。

## 任务 3：实现自测内联批阅

- 扩展 `practiceState` 保存批阅结果、开始时间和提交状态。
- 修改证明题渲染恢复结果和提交按钮状态。
- 调用 `/api/grading/grade`，成功后按规则上报 `/api/learning/events`，失败支持重试。
- 添加真实响应字段的结果卡渲染。

## 任务 4：样式与兼容

- 添加紧凑的证明题批阅卡样式。
- 保持选择题、填空题和旧兼容批阅逻辑不变。

## 任务 5：验证

- 运行 Node 语法检查、Python 编译检查、目标 pytest。
- 用 FastAPI TestClient 或本地 API 验证批阅接口契约；记录模型服务不可用等环境限制。
- 检查 diff 后提交 feature 分支。
