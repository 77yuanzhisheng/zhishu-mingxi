# 队员4演示脚本

## 1. 分步证明

进入“自测练习 > 大题”，选择证明题。每完成一步点击“记录本步”，完成证明后提交五维批阅。批阅结果出现后点击“展示第一步”，逐步讲解参考推导，强调参考答案在作答完成前不会显示。

## 2. 图谱融合

进入“知识图谱 > 融合导航”，依次选择章、小节和教材知识点。知识点右侧直接显示平台掌握状态；点击知识点后，下方同步展示知识内容、学情和推荐题目。

## 3. 智能备课

使用教师身份进入“智能备课”，选择章节、小节、授课对象、课时和内容类型。生成后展示可直接使用的教学目标、时间分配、关键推导、课堂活动和课后练习。

## 4. 智能体通道

进入“知识库 RAG”提问。星辰 Agent 正常返回时，标题区和回答上方显示绿色“星辰 Agent”；智能体接口缺失或异常时自动改走 Qwen3，并显示黄色“Qwen3 降级”和原因。学习陪伴、智能备课使用同一通道策略。

## 5. 赛事合规材料

进入“赛事平台合规”，依次选择 MaaS 微调、Agent 配置、应用调用三类真实截图和三段真实录屏。页面显示 6 项材料完成度，可直接检查图片和视频；文件只在当前浏览器本地预览，不上传到业务后端。
