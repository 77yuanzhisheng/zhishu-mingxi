# 队员4演示脚本

## 1. 分步证明

进入“自测练习 > 大题”，选择证明题。每完成一步点击“记录本步”，完成证明后提交五维批阅。批阅结果出现后点击“展示第一步”，逐步讲解参考推导，强调参考答案在作答完成前不会显示。

## 2. 图谱融合

进入“知识图谱 > 融合导航”，依次选择章、小节和教材知识点。知识点右侧直接显示平台掌握状态；点击知识点后，下方同步展示知识内容、学情和推荐题目。

## 3. 智能备课

使用教师身份进入“智能备课”，选择章节、小节、授课对象、课时和内容类型。生成后展示可直接使用的教学目标、时间分配、关键推导、课堂活动和课后练习。
