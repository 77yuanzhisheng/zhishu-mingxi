## ③ 星辰 Agent 知识库兼容说明

1. **知识库导入**：在讯飞星辰平台“知识库”中直接上传 `知数明析_星辰知识库.md`（Markdown 分节：`#` 模块 / `##` 符号 / `###` 概念 / `####` 一级知识点 / `-` 条目；例题与答案以加粗题号开头）。平台按分块+向量检索，格式要求为常见 Markdown，无需特殊字段。
2. **指令微调**：通用微调平台通常接受 OpenAI `messages` JSONL（`知数明析_指令集.jsonl`）——每行 `{"messages":[{"role":"system",...},{"role":"user",...},{"role":"assistant",...}]}`；若平台要求平铺键，用 `知数明析_指令集_triplet.jsonl`。
3. 若星辰仅提供知识库+提示词（无微调通道），可将 `知数明析_指令集.jsonl` 抽样作为“示范样例”写入提示词，知识库仍以 md 导入。

## 正确性保证（②）

- 所有 assistant 内容 = 教师题库/教材图谱原文或原文字串拼接（不生成新内容），模板只变化 user 问法 → 杜绝编造。
- 每条 answer 附“知识点：xx（图谱节点 xxx）”溯源标记（来源 `data/documents/老师训练题库_node_id.json`）。
- OCR 短句仅收录“教材一致”正例，且严格筛选为陈述句（排除标题/编号标签/例题图注）。
- `数据审计.md` 列出全部未收录 LaTeX 命令，便于人工扩充 `SYMB_MAP`。
