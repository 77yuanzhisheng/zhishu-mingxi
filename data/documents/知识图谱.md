# 离散数学知识图谱

离散数学核心五大模块及其依赖关系：

```

          ┌─────────────┼─────────────┐
          ▼             ▼             ▼

   │(扩展逻辑) │  │(数学基础)  │  │(证明工具) │

        │              │             │
```

## 模块一：命题逻辑

**前置知识**：无
**核心概念**：命题、联结词(¬,∧,∨,→,↔)、真值表、逻辑等价、重言式、范式(DNF/CNF)、推理规则
**关联到**：谓词逻辑、数字电路设计、程序正确性验证
**典型题型**：真值表构造、逻辑等价证明、范式转换、推理有效性判断

## 模块二：谓词逻辑

**前置知识**：命题逻辑
**核心概念**：谓词、量词(∀,∃)、约束/自由变元、量词否定律、UI/UG/EI/EG推理规则
**关联到**：集合论(集合的谓词定义)、关系(关系的谓词表示)、数据库查询(SQL)
**典型题型**：谓词公式翻译、量词否定、推理有效性

## 模块三：集合论

**前置知识**：命题逻辑
**核心概念**：集合表示、子集、幂集、并/交/差/补/对称差、笛卡尔积、运算定律
**关联到**：关系(基于笛卡尔积)、图论(顶点集+边集)、概率论(事件=集合)
**典型题型**：集合相等证明、运算定律证明、基数计算、文氏图

## 模块四：关系

**前置知识**：集合论、谓词逻辑
**核心概念**：二元关系、关系矩阵、自反/对称/传递性、等价关系(等价类/划分)、偏序关系(哈斯图)
**关联到**：图论(关系=有向图)、数据库(表间关系)、软件工程(依赖关系)
**典型题型**：性质判定、关系矩阵运算、等价类划分、哈斯图绘制

## 模块五：图论

**前置知识**：关系、集合论
**核心概念**：顶点/边、度(握手定理)、路径/回路、连通性、欧拉图/哈密顿图、树、二部图、邻接矩阵
**关联到**：网络路由、社交网络分析、编译器(语法树)、电路设计
**典型题型**：握手定理应用、树的性质证明、欧拉/哈密顿判定、邻接矩阵幂

## 模块六：数学归纳法

**前置知识**：命题逻辑、谓词逻辑
**核心概念**：基础步、归纳步、归纳假设、强归纳法、结构归纳法
**关联到**：所有需要证明∀nP(n)的问题
**典型题型**：求和公式证明、不等式证明、整除性证明、递推关系

## 学习方法路径

```
入门推荐顺序：
命题逻辑 → 集合论 → 谓词逻辑 → 数学归纳法 → 关系 → 图论

关键依赖链：
命题逻辑（基本推理）→ 数学归纳法（证明工具）→ 贯穿所有证明题
集合论（基本对象）→ 关系（对象间联系）→ 图论（可视化关系）
```

## 概念关联图

- 命题 ↔ 集合（命题→{T,F}，集合→{元素})
- 联结词 ↔ 集合运算（∧↔∩, ∨↔∪, ¬↔补）
- 蕴含式 ↔ 子集（P→Q ≡ P⊆Q在逻辑意义下）
- 量词 ↔ 集合（∀x∈A↔全称量词，∃x∈A↔存在量词）
- 关系 ↔ 有向图（关系=有向图的边集描述）
- 等价类 ↔ 划分（一一对应）
- 偏序 ↔ 哈斯图（可视化）
- 树 ↔ 无回路连通图 ↔ n-1条边
- 归纳法 ↔ 递归 ↔ 树结构证明
