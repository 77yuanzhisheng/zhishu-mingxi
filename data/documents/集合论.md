# 集合论基础

## 1. 集合的基本概念

**定义1（集合）**：一些确定对象的全体，这些对象称为集合的元素。通常用大写字母A、B、C表示集合，小写字母a、b、c表示元素。

a∈A 表示a是A的元素；a∉A 表示a不是A的元素。

集合的表示方法：
- 列举法：A = {1, 2, 3, 4, 5}
- 描述法：B = {x | x是偶数}
- 文氏图：用平面区域直观表示集合

## 2. 集合间关系

**定义2（子集）**：若A中每个元素都是B的元素，则称A是B的子集，记作A⊆B。

**定义3（相等）**：A=B 当且仅当 A⊆B 且 B⊆A。

**定义4（真子集）**：A⊂B 当且仅当 A⊆B 且 A≠B。

**定义5（幂集）**：集合A的所有子集构成的集合，记作P(A)。若|A|=n，则|P(A)|=2^n。

## 3. 集合运算

**定义6（并集）**：A∪B = {x | x∈A 或 x∈B}

**定义7（交集）**：A∩B = {x | x∈A 且 x∈B}

**定义8（差集）**：A−B = {x | x∈A 且 x∉B}

**定义9（补集）**：设全集为U，~A = U−A

**定义10（对称差）**：A⊕B = (A−B)∪(B−A)

## 4. 集合运算定律

| 定律 | 公式 |
|------|------|
| 幂等律 | A∪A=A, A∩A=A |
| 交换律 | A∪B=B∪A, A∩B=B∩A |
| 结合律 | (A∪B)∪C=A∪(B∪C) |
| 分配律 | A∩(B∪C)=(A∩B)∪(A∩C) |
| 吸收律 | A∪(A∩B)=A |
| 德摩根律 | ~(A∪B)=~A∩~B, ~(A∩B)=~A∪~B |

## 5. 笛卡尔积

**定义11（有序对）**：(a,b) 是一个有序对，其中a是第一元素，b是第二元素。有序对的特点是 (a,b)=(c,d) 当且仅当 a=c 且 b=d。

**定义12（笛卡尔积）**：A×B = {(a,b) | a∈A, b∈B}

若|A|=m, |B|=n，则|A×B|=mn。
