# 关系

## 1. 关系的基本概念

**定义1（关系）**：设A、B为集合，A×B的任意子集称为从A到B的一个二元关系。特别地，A×A的子集称为A上的二元关系。

若(a,b)∈R，则称a与b有关系R，记作aRb。

**定义2（关系矩阵）**：设A={a1,...,am}, B={b1,...,bn}，关系R的关系矩阵M_R是一个m×n的(0,1)矩阵，其中：
- M_R[i][j] = 1，若aiRbj
- M_R[i][j] = 0，否则

例如，若A={1,2,3}上的关系R={(1,1),(1,2),(2,3),(3,1)}，则关系矩阵为：
```
    b1 b2 b3
a1 [ 1  1  0 ]
a2 [ 0  0  1 ]
a3 [ 1  0  0 ]
```

## 2. 关系的性质

**定义3**：设R是集合A上的二元关系：

- **自反性**：∀a∈A，有aRa。关系矩阵主对角线全为1。
- **反自反性**：∀a∈A，有¬(aRa)。关系矩阵主对角线全为0。
- **对称性**：若aRb，则bRa。关系矩阵是对称矩阵。
- **反对称性**：若aRb且bRa，则a=b。关系矩阵中，若i≠j且M[i][j]=1，则M[j][i]=0。
- **传递性**：若aRb且bRc，则aRc。关系矩阵满足M^2⊆M。

判断方法：给定关系矩阵，逐一验证以上性质。

## 3. 等价关系

**定义4（等价关系）**：同时满足自反性、对称性和传递性的关系。

**定义5（等价类）**：设R是A上的等价关系，a∈A，则[a]_R = {x∈A | xRa}称为a关于R的等价类。

**定理1**：等价关系将集合划分为互不相交的等价类。

常见的等价关系：相等关系、模n同余关系。

## 4. 偏序关系

**定义6（偏序关系）**：同时满足自反性、反对称性和传递性的关系。记作"≤"。

**定义7（偏序集）**：集合A连同其上的偏序关系≤，记作(A,≤)。

偏序集中的特殊元素：
- 极大元/极小元
- 最大元/最小元
- 上界/下界、上确界/下确界

**哈斯图**：偏序集的可视化表示，省略自反边和传递边。

## 5. 等价关系与偏序关系的区别

| 性质 | 等价关系 | 偏序关系 |
|------|---------|---------|
| 自反性 | ✓ | ✓ |
| 对称性 | ✓ | ✗（反对称） |
| 传递性 | ✓ | ✓ |
| 典型用途 | 分类/划分 | 层次/排序 |
