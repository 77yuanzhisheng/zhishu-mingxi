# 命题逻辑

## 1. 命题与联结词

**定义1（命题）**：一个具有确定真值的陈述句称为命题。真值只有真（T）和假（F）两种。

例如："北京是中国的首都"是真命题；"2+3=6"是假命题；疑问句、祈使句不是命题。

**定义2（联结词）**：将命题组合成复合命题的逻辑运算符。

| 联结词 | 符号 | 含义 | 真值条件 |
|--------|------|------|----------|
| 否定 | ¬P | 非P | 与P相反 |
| 合取 | P∧Q | P且Q | 两者皆真 |
| 析取 | P∨Q | P或Q | 至少一真 |
| 蕴含 | P→Q | 若P则Q | P真Q假时为假 |
| 等价 | P↔Q | P当且仅当Q | 两者同真值 |

## 2. 真值表与逻辑等价

**定义3（真值表）**：将命题公式在所有可能赋值下的真值列成的表。

**定理1（德摩根律）**：
- ¬(P∧Q) ≡ ¬P∨¬Q
- ¬(P∨Q) ≡ ¬P∧¬Q

证明：列出P、Q的所有可能取值（共4种），分别计算两边公式的值，发现两列完全相同。

**定义4（逻辑等价）**：如果两个命题公式在所有赋值下都有相同的真值，则称它们逻辑等价，记作P≡Q。

## 3. 重言式与蕴含式

**定义5（重言式）**：在所有赋值下都为真的命题公式，也称为永真式。

**定义6（矛盾式）**：在所有赋值下都为假的命题公式，也称为永假式。

常见重言式：P∨¬P（排中律）、¬(P∧¬P)（矛盾律）、P→P（同一律）

## 4. 范式

**定理2（范式存在定理）**：任一命题公式都存在与之等价的析取范式和合取范式。

- 析取范式（DNF）：若干简单合取式的析取
- 合取范式（CNF）：若干简单析取式的合取
- 主析取范式：每个简单合取式包含所有命题变元
- 主合取范式：每个简单析取式包含所有命题变元

## 5. 推理规则

| 规则 | 形式 |
|------|------|
| 假言推理 | P→Q, P ⊢ Q |
| 拒取式 | P→Q, ¬Q ⊢ ¬P |
| 假言三段论 | P→Q, Q→R ⊢ P→R |
| 析取三段论 | P∨Q, ¬P ⊢ Q |
| 附加律 | P ⊢ P∨Q |
| 化简律 | P∧Q ⊢ P |
| 合取律 | P, Q ⊢ P∧Q |
